FraudGuard

A cloud-native transaction screening platform designed as a distributed microservice system across Kubernetes and Microsoft Azure. The application screens transaction batches using independently deployed screening services, routes requests through resilient proxy instances with failover and circuit-breaker protection, and continuously monitors service health. It also integrates Azure-hosted persistence, allowing transaction batches to be saved and recalled using unique identifiers while keeping the core screening services stateless.
