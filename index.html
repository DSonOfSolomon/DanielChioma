Hi, I am Daniel Chioma

A backend-focused software engineer who builds scalable, real-world systems. I recently created an anonymous crowd-advice platform for my 80,000+ followers on Instagram and TikTok, designed to handle high volumes of dilemmas and let the community vote on verdicts. Messages are routed via an opt-in link, forming a human-in-the-loop system where community judgment drives moderation and aggregated verdicts. Feedback loops shape user behaviour, and the platform is designed to handle emergent social dynamics. I developed the frontend with React and the backend using Spring Boot with H2 and then PostgreSQL for data persistence. The system features role-based access control, vote-processing logic, and paginated APIs to ensure smooth, reliable interactions. I enjoy designing RESTful APIs, working with databases, and integrating human behaviour into scalable systems.
